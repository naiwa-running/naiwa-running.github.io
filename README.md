# 奶蛙快跑 · Naiwa Running

一个三维跑酷小游戏：奶蛙在奶国里一路狂奔，躲开障碍、攒奶蛋，别被肥嘟嘟抓住！

**在线游玩：<https://naiwa-running.github.io/>**（手机、电脑浏览器都能玩）

整个游戏打包成一个 `index.html`，下载下来双击就能离线玩。

## 怎么玩

| 操作 | 手机 | 电脑 |
|---|---|---|
| 换道 | 左右滑 | ← → / A D |
| 跳跃 | 上滑 | ↑ / W |
| 趴下 | 下滑 | ↓ / S |
| 空翻 | 跳起来后轻点屏幕 | 空中按空格 |
| 前滚翻 | 趴着时再下滑一次 | 趴着时再按 ↓ |

- 撞到一次障碍，肥嘟嘟就会追上来；被追时再撞一次就会被抓住。
- 五条道，倾斜的奶车要从坡道正面跑上去。
- 道具：吸奶石、跳蛋、双倍奶蛋、奶泡护罩、奶瓶火箭。
- 奶金可以用来复活、买皮肤、进药水关卡。
- 药水关卡里喝下增强药水会变身西格奶，回头反追肥嘟嘟。
- 收集路上的雕像填满图鉴；集齐奶十二生肖可以兑换最稀有的皮肤「奶神」。
- 抽奖机（单抽 / 十连，百抽保底传说）和 30 个成就。

## 从源码构建

需要 Node.js 18 或以上。

```bash
npm install
npm run build   # 生成 index.html
```

- `src/main.js`：游戏逻辑、界面、存档
- `src/chars.js`：奶蛙、肥嘟嘟、西格奶等角色的程序化模型和动作
- `src/models.js`：障碍物、道具、场景模型
- `src/statues.js` / `src/statueImgs.js`：图鉴雕像（图片浮雕）
- `src/audio.js`：音效与背景音乐（WebAudio 现场合成）
- `template.html`：页面结构和样式，构建时把打包好的脚本嵌进去

渲染使用 [three.js](https://threejs.org/)，打包使用 [esbuild](https://esbuild.github.io/)。
